## 요구사항

### [ 목표 ]

- 자바스크립트로 정렬 알고리즘 구현하기

### [ 작업 내용 ]

- [ ] 선택 정렬 (Selection sort) : 숫자형 배열을 파라미터로 받고, 해당 배열을 수정하도록 구현합니다.
- [ ] 삽입 정렬 (Insertion sort) : 숫자형 배열을 파라미터로 받고, 해당 배열을 수정하도록 구현합니다.
- [ ] 병합 정렬 (Merge sort) : 숫자형 배열을 파라미터로 받고, 정렬된 새로운 배열을 리턴하도록 구현합니다.
- [ ] 퀵 정렬 (Quick sort) : 숫자형 배열을 파라미터로 받고, 해당 배열을 수정하도록 구현합니다.

- 함수 예시

```javascript
const nums = [3, 1, 2];
console.log(nums); // [3, 1, 2];
selectionSort(nums);
console.log(nums); // [1, 2, 3]
```
